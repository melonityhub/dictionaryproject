# دیکشنری و مترجم آفلاین (بازسازی)

برنامه‌ی گرافیکی (PySide6):

1. **جستجو** در `fastdic_plain.sqlite` با همان کوئری‌ها (GLOB انگلیسی، جستجوی فارسی با ستون `word_in_number`،
   سقف ۵۰ نتیجه، ۲ مورد تاریخچه، پیشنهاد Levenshtein ≤ ۲، تبدیل عدد به حروف).
2. **نمایش نتیجه** هم‌ساختار با `FDHtml`: معنی‌ها + جمله‌ها، هم‌معنی/متضاد، فعل‌های عبارتی، هم‌نشینی‌ها، اصطلاح‌ها،
   خانواده‌ی واژه، تلفظ آمریکایی/بریتانیایی (پخش از CDN فستدیک)، صورت‌های فعل/اسم، CEFR، دسته‌ها.
3. **ترجمه‌ی آفلاین متن** با همان بسته‌ی گوگل (`*.bipe` + `resources/`) روی CPU، بدون اینترنت.
4. **تاریخچه** (سقف ۱۰۰، مثل اپ) و **علاقه‌مندی‌ها**.

## اجرا
```
pip install -r requirements.txt        # پایتون ۳٫۱۰ تا ۳٫۱۳
python run.py                          # یا در ویندوز: run.bat
```
در **⚙ تنظیمات** این‌ها را انتخاب کنید:
- فایل `fastdic_plain.sqlite`
- نمونه ی کوچک شده دیتا بیس در doc/sample.sqlite هست و توضیحات داده شده
- پوشه‌ای که `translate_faen` (و در صورت داشتن، `translate_enfa`) داخل آن است.
  هر زیرپوشه‌ای که `translation_model.pb` داشته باشد خودکار شناسایی و جهتش از خود فایل خوانده می‌شود.

خودآزمایی بدون GUI: `python selftest.py fastdic_plain.sqlite <پوشه‌ی مدل‌ها>`

## چه چیزی «عیناً از کد اندروید» است و چه چیزی بازسازی؟
| بخش | وضعیت |
|---|---|
| کوئری‌های SQL، ترتیب مرتب‌سازی، `trimmingAndLowerCaseWords`، `charReplacement`، `peCharacterToNumber`، تشخیص زبان، نگاشت نقش دستوری و دسته‌ها | **از سورس جاوا برداشته شده** (جدول‌ها خودکار استخراج شده‌اند). ستون `word_in_number` روی ۳۹۷ ردیف نمونه با ۰ اختلاف بازتولید می‌شود. |
| اجرای مدل‌های `.bipe` | **بازسازی کامل با مهندسی معکوس** (فرمت در `docs/BIPE_FORMAT.md`). ترجمه‌ها روان و صحیح‌اند. |
| پیش‌پردازش/توکنایز، beam search، جریمه‌ی طول، detokenize | **بازسازی** (کد اصلی داخل کتابخانه‌ی بومی ML Kit است). خروجی ممکن است گاهی با ML Kit کمی فرق کند. |
| CSS نمایش (`style-results.css`) | **در آرشیو نبود**؛ استایل خودم است. متن برچسب‌های `R.string.*` هم نبود؛ فارسی ساده نوشته‌ام. |
| تبدیل عدد به حروف | ماژول بیرونی اپ در آرشیو نبود؛ نسخه‌ی ساده‌ی خودم (فقط عدد صحیح). |
| Parse/Couchbase، اشتراک، تبلیغات، همگام‌سازی ابری، OCR/تصویر | **پیاده نشده** (تاریخچه/علاقه‌مندی روی SQLite محلی `~/.fastdic_desktop/`). |

## محدودیت‌های مهم
- **فقط جهتی کار می‌کند که بسته‌اش را بدهید.** الان `translate_faen` (فارسی→انگلیسی) را دارید؛ برای انگلیسی→فارسی
  باید پوشه‌ی `translate_enfa` را همان‌طور از گوشی/APK بردارید. جهت en→fa روی داده‌ی واقعی **آزمایش نشده**
  (پیش‌پردازش آن، مثلاً lowercase، از روی vocab همان بسته حدس زده می‌شود).
- هر دسته‌ی ترجمه حداکثر ۷۲ توکن است؛ متن‌های بلند خودکار به جمله/تکه شکسته می‌شوند.
- مدل ترجمه مال گوگل است؛ شرایط استفاده‌ی ML Kit برای آن اعمال می‌شود.
