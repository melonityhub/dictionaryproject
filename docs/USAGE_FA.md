# راهنمای اجرا و راه‌اندازی

## ۱) نصب و اجرا

```bash
pip install -r requirements.txt        # پایتون ۳٫۱۰ تا ۳٫۱۳
python run.py                          # در ویندوز: run.bat
```

## ۲) دیتابیس اصلی فرهنگ لغت

دیتابیس اصلی از Releaseهای همین مخزن قابل دریافت است:

```
https://github.com/melonityhub/dictionaryproject/releases/download/db1.0.0/main_db.sqlite
```

فایل `main_db.sqlite` را دانلود کنید، سپس در برنامه از **⚙ تنظیمات** آن را به‌عنوان
«فایل دیتابیس» انتخاب کنید (نام فایل مهم نیست؛ هر مسیری بدهید همان خوانده می‌شود).
یک نمونهٔ کوچک برای آزمایش هم در `docs/sample.sqlite` هست.

## ۳) مدل‌های ترجمهٔ آفلاین (ML Kit)

در تب **مترجم متن** زبان مقصد را از فهرست انتخاب کنید و با دکمهٔ **مدل‌ها…** همان مدل
را دانلود کنید. مدل‌ها همان بسته‌های آفلاین Google Translate / ML Kit هستند و از سرورهای
رسمی گوگل دریافت می‌شوند؛ جزئیات کامل (منبع دانلود، `DL_SZ`، هش SHA-256، محل کش محلی و
حذف مدل) در [`MLKIT_TRANSLATION_MODELS_FA.md`](MLKIT_TRANSLATION_MODELS_FA.md) آمده است.

پوشهٔ مدل‌ها به‌طور پیش‌فرض `~/.fastdic_desktop/models/` است و از ⚙ تنظیمات قابل تغییر است.
پس از یک بار دانلود، ترجمه همیشه آفلاین انجام می‌شود.

## ۴) خودآزمایی بدون رابط گرافیکی

```bash
python selftest.py <main_db.sqlite> <پوشه‌ی مدل‌ها>
```
