# دیکشنری و مترجم آفلاین (بازسازی)

برنامه‌ی گرافیکی (PySide6):

1. **جستجو** در `fastdic_plain.sqlite` با همان کوئری‌ها (GLOB انگلیسی، جستجوی فارسی با ستون `word_in_number`، سقف ۵۰ نتیجه، ۲ مورد تاریخچه، پیشنهاد Levenshtein ≤ ۲ و تبدیل عدد به حروف).
2. **نمایش نتیجه** هم‌ساختار با `FDHtml`: معنی‌ها و جمله‌ها، هم‌معنی/متضاد، فعل‌های عبارتی، هم‌نشینی‌ها، اصطلاح‌ها، خانواده‌ی واژه، تلفظ آمریکایی/بریتانیایی، صورت‌های فعل/اسم، CEFR و دسته‌ها.
3. **ترجمه‌ی متن به‌صورت آفلاین** با بسته‌های مدل Google ML Kit (`translation_model.pb`، فایل‌های `.bipe` و منابع مدل) روی CPU.
4. **تاریخچه و علاقه‌مندی‌ها** به‌صورت محلی.

## اجرا

```bash
pip install -r requirements.txt        # پایتون ۳٫۱۰ تا ۳٫۱۳
python run.py                          # یا در ویندوز: run.bat
```

در **⚙ تنظیمات** فایل `fastdic_plain.sqlite` را انتخاب کنید. نمونه‌ی کوچک دیتابیس در `docs/sample.sqlite` است. پوشه‌ی مدل‌ها به‌طور پیش‌فرض در `~/.fastdic_desktop/models/` نگه‌داری می‌شود و از تنظیمات قابل تغییر است.

## دانلود مدل‌های ترجمه از داخل برنامه

در تب **مترجم متن** روی **دانلود/مدیریت مدل‌ها** بزنید. برای هر جهت یک ردیف جدا وجود دارد:

- **فارسی → انگلیسی (`fa→en`)**
- **انگلیسی → فارسی (`en→fa`)**

نشانی مستقیم **HTTPS** یک فایل ZIP سازگار را در ردیف همان جهت وارد و دانلود را آغاز کنید. برنامه جهت زبان را با جهت انتخاب‌شده تطبیق می‌دهد، فایل‌های اصلی مدل را بررسی می‌کند و بسته را با استخراج امن نصب می‌کند. بسته باید یک `translation_model.pb`، فایل‌های مدل `.bipe` و واژگان/منابعی را که manifest معرفی می‌کند داشته باشد؛ یک پوشه‌ی ریشه‌ی اضافی داخل ZIP هم پذیرفته می‌شود. پس از نصب، جهت ترجمه از روی زبان متن به‌طور خودکار انتخاب می‌شود و اجرای ترجمه آفلاین است؛ فقط دریافت اولیه‌ی مدل به اینترنت نیاز دارد.

این نسخه بسته‌ی مدل را در مخزن قرار نمی‌دهد و URL آماده‌ای هم از پیش تنظیم نشده است؛ کاربر باید نشانی مستقیم ZIP سازگار را از منبع موردنظرش وارد کند. این ابزار دانلود از مدل‌منیجر اندرویدی Google Play Services استفاده نمی‌کند؛ فایل باید با قالب بسته‌ای که برنامه می‌خواند سازگار باشد.

خودآزمایی بدون GUI: `python selftest.py fastdic_plain.sqlite <پوشه‌ی مدل‌ها>`

## چه چیزی «عیناً از کد اندروید» است و چه چیزی بازسازی؟

| بخش | وضعیت |
|---|---|
| کوئری‌های SQL، ترتیب مرتب‌سازی، `trimmingAndLowerCaseWords`، `charReplacement`، `peCharacterToNumber`، تشخیص زبان، نگاشت نقش دستوری و دسته‌ها | **از سورس جاوا برداشته شده** (جدول‌ها خودکار استخراج شده‌اند). ستون `word_in_number` روی ۳۹۷ ردیف نمونه با ۰ اختلاف بازتولید می‌شود. |
| اجرای مدل‌های `.bipe` | **بازسازی کامل با مهندسی معکوس** (فرمت در `docs/BIPE_FORMAT.md`). |
| پیش‌پردازش/توکنایز، beam search، جریمه‌ی طول و detokenize | **بازسازی** (کد اصلی داخل کتابخانه‌ی بومی ML Kit است). خروجی ممکن است گاهی با ML Kit کمی فرق کند. |
| CSS نمایش (`style-results.css`) | **در آرشیو نبود**؛ استایل خودم است. متن برچسب‌های `R.string.*` هم نبود؛ فارسی ساده نوشته‌ام. |
| تبدیل عدد به حروف | ماژول بیرونی اپ در آرشیو نبود؛ نسخه‌ی ساده‌ی خودم (فقط عدد صحیح). |
| Parse/Couchbase، اشتراک، تبلیغات، همگام‌سازی ابری، OCR/تصویر | **پیاده نشده** (تاریخچه/علاقه‌مندی روی SQLite محلی `~/.fastdic_desktop/`). |

## محدودیت‌ها

- هر جهتی که بسته‌ی مدل سازگارش نصب شود قابل‌استفاده است؛ دانلود `fa→en` و `en→fa` جداگانه است. خروجی جهت `en→fa` با مدل واقعی در این بازسازی هنوز آزمایش نشده است.
- هر دسته‌ی ترجمه حداکثر ۷۲ توکن است؛ متن‌های بلند خودکار به جمله/تکه شکسته می‌شوند.
- تلفظ‌های صوتی از CDN فست‌دیک پخش می‌شوند؛ بنابراین این قابلیت به اینترنت نیاز دارد، حتی وقتی ترجمه‌ی مدل آفلاین است.
